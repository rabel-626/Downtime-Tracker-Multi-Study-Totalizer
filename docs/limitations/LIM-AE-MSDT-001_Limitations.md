# Multi-Study Downtime Totalizer — Limitations

- Combined results are only as comparable as the source studies.
- Different reason-code definitions can create misleading aggregation.
- Different observation durations can distort raw-duration comparisons.
- Product, shift, line, and operating-condition differences should be reviewed before drawing causal conclusions.
- Aggregation identifies patterns; it does not establish root cause.
