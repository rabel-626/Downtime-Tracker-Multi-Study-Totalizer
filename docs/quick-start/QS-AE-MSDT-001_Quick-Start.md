# Multi-Study Downtime Totalizer — Quick Start

1. Export or collect compatible Downtime Tracker study JSON files.
2. Open the totalizer.
3. Select individual JSON files or load a study folder.
4. Confirm the expected studies appear in **Loaded Study Reference**.
5. Review the **Combined Downtime Pareto**.
6. Use the study slicer to isolate individual study contributions.
7. Review the calculation/reference tab as needed.
8. Export the consolidated analysis.
