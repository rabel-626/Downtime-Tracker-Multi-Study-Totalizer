# Multi-Study Downtime Totalizer — Data & Privacy

The totalizer reads user-selected downtime study files in the browser for analysis.

Recommended practice:

- Keep source JSON studies unchanged.
- Retain the list of studies used for an exported consolidated result.
- Avoid mixing study files from unrelated analyses without documenting why.
- Follow applicable requirements for production and customer data.
