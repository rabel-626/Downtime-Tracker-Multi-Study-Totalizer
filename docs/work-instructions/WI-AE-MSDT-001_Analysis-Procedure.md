# Multi-Study Downtime Totalizer — Work Instructions

## 1. Prepare Source Studies

Use saved Downtime Tracker JSON studies. Before combining them, confirm that reason-code definitions and study scope are sufficiently compatible for the intended comparison.

## 2. Load Studies

Load the desired files or a parent study folder. Review the loaded-study list and remove unintended files.

## 3. Review Combined Pareto

Use the combined Pareto to identify high-duration reason categories across the selected studies.

## 4. Isolate Contributions

Use the study slicer to determine whether a combined result is broadly recurring or dominated by one study.

## 5. Export

Export the consolidated analysis only after confirming the source study set.
