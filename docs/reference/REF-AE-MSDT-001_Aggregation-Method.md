# Multi-Study Downtime Totalizer — Aggregation Method

The totalizer combines compatible source-study records by reason code and preserves study reference information for review.

## Comparison Principle

A large combined total can result from:

- A recurring problem across many studies
- One severe event in a single study
- Different study durations
- Different production conditions

Use the study slicer and source metadata before interpreting the combined ranking as a plant-wide priority.
